Replay: one PNG encode, recorded on an RX 590, without the encoder

This page replays a recording of every WebGPU call one PNG encode made (traces/png_first_encode_rx590.jsonl: a 512 x 512 photo, SpawnDev.Codecs' GPU PNG encoder at commit f16ef38, recorded on an AMD Radeon RX 590 where that encoder's files did not decode). Only WebGPU calls are replayed: no SpawnDev code. The page then hands the PNG the GPU wrote to the browser's own PNG decoder: a right encoder output decodes, the RX 590's did not (its DEFLATE Huffman codes were wrong). It runs by itself and takes some seconds.
