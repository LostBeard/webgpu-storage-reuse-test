Does one WebGPU invocation read back what it just wrote to a storage buffer?

One invocation (workgroup size 1, one workgroup) builds three canonical Huffman codes in a row (the DEFLATE literal, distance and code-length codes, as an encoder does). Each build zeroes 16 counters in a storage buffer, counts the code lengths into them, and reads them back to compute the first code of each length. All three builds use the same 16 counter slots. WGSL orders one invocation's own accesses: every read must see that invocation's latest write. The page compares the codes with the same computation in JavaScript. Plain WebGPU, no libraries. It runs by itself.
